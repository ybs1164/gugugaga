# 전투 HUD 픽셀 리디자인 — 초안 계획

전투 화면 HUD(`View/BattleHud`, `View/FaithPunchHud`)를 **포인트 컬러 하나 + 무채색 단계**의 픽셀 스타일로 다시 그리는 계획.
배치의 기준은 기획 시안(상단 1~5, 하단 6~9)이고, 시안의 색·아이콘은 설명용 임시 표시이므로 따르지 않는다.
현재 화면 배치의 단일 출처는 [session — 화면 배치](spec/game/session.md#화면-배치)이며, 이 계획이 구현되면 그 문서를 고친다(이 파일은 계획일 뿐 현재 동작이 아니다).

## 1. 원칙

1. **색은 의미가 아니라 주목도다.** 포인트 컬러는 "지금 눌러야 하는 것 / 지금 쓸 수 있는 것"에만 칠한다. 화면 위에 동시에 포인트 컬러가 칠해진 요소는 **최대 2개**.
2. **나머지는 무채색 5단계**(배경 ← → 글자). 상태 구분은 색 대신 **채움/테두리/아이콘/명도**로 한다.
3. **중요도 = 크기·위치.** 자주 누르고 판단에 직접 쓰이는 것일수록 크고 엄지 가까이(하단), 참고용일수록 작고 위·바깥에.
4. **픽셀 규칙 유지.** 정수 배율, Point 필터, 1텍셀 외곽선(#0C080A, `PixelSpriteComposer.Outline`), 9-slice 틀 — 지금 [UI 해상도](spec/csv/sprites.md#ui-해상도) 규칙을 그대로 쓴다.

## 2. 팔레트

| 토큰 | 용도 | 비고 |
|---|---|---|
| `Ink` | 외곽선, 가장 어두운 그림자 | 기존 외곽선 색 그대로 |
| `Base` | 막대·패널 바탕 | 지금 `UiKit.PanelColor` 자리 |
| `Raised` | 버튼 바탕, 칩 바탕 | 지금 `ButtonColor` 자리 |
| `Muted` | 보조 글자, 비활성 아이콘, 구분선 | 지금 `MutedText`·`DisabledText` 통합 |
| `Paper` | 본문 글자, 아이콘 기본 | 흰색보다 살짝 따뜻한 회백색 |
| `Accent` | **포인트 컬러 1개** | 호박색 |

- 포인트 컬러는 **호박색**으로 정했다(신앙·금화와 연결된다). 정확한 색값은 지도(지형·팀 색)와 겹치지 않는지 실제 화면 캡처로 확인하며 정한다.
- `Accent`는 명도 2단(`Accent`, `AccentDark` = 베벨 그림자)만 허용. 9-slice 틀은 지금처럼 무채색으로 그리고 `Image.color`로 물들인다.
- 지금 HUD에 흩어진 색(`PrimaryColor`, `StarColor`, `FaithColor`, 턴 표시의 `PlayerAccent`/`EnemyAccent`)은 위 토큰으로 흡수한다. **팀 색은 지도(유닛 배지)에만 남기고 HUD에서는 뺀다** — 적 턴은 색 대신 "적 차례" 문구 + 턴 종료 버튼 잠금으로 보여 준다.

## 3. 중요도 등급

| 등급 | 요소 | 판단 근거 | 표현 |
|---|---|---|---|
| A — 행동 | 9 턴 종료, 7 신앙 펀치 | 매 턴 누르며, 누를 타이밍이 중요 | 하단, 가장 큰 버튼, 상태에 따라 `Accent` |
| B — 자원 | 2 신앙 포인트, 3 골드 | 매 행동 전 확인하는 숫자 | 상단 가운데, 큰 숫자(2배 글자) |
| C — 맥락 | 4 턴, 1 신앙 순위 | 가끔 보는 진행 정보 | 상단 양쪽, 작은 숫자 |
| D — 도구 | 5 메뉴, 6 정보, 8 기술 트리 | 필요할 때만 여는 창 | 아이콘만, 무채색, 작은 버튼 |

> 시안은 하단 4버튼이 같은 크기지만, 이 등급에 따라 **9 > 7 > 8 = 6** 으로 폭을 다르게 한다(순서는 시안 유지).

## 4. 요소별 디자인

### 상단 막대 (1~5)
`[1 순위] [2 신앙 ▮▮▮▯] [3 골드] [4 턴]  ……  [5 ⚙]` — 칩(Badge 틀) 한 줄, 좁은 배치에서도 한 줄 유지(지금의 두 줄 막대를 없앤다).

| # | 내용 | 아이콘(16×16) | 상태 표현 |
|---|---|---|---|
| 1 | 신앙 순위 `n/전체` — 기존 [신앙 순위](spec/game/faith.md)(살아 있는 유닛 수, 공동 순위 포함) | 왕관 | 1위일 때만 왕관을 `Accent`. 나머지는 `Paper`. 누르면 말풍선: 유닛 수 · 다음 순위까지 필요한 유닛 수 · 순위 보너스(`Faith.RankBonus*`) |
| 2 | 신앙 `현재/최대` + 아래 1텍셀 게이지 | 불꽃 | 최대치 도달 시 게이지 `Accent`(넘치는 신앙이 버려진다는 신호). 다음 턴 수입은 누르면 말풍선 |
| 3 | 골드(현재의 "별") `0~999` | 동전 더미 | 이번 턴 살 수 있는 게 없으면 숫자를 `Muted` |
| 4 | 턴 `현재/제한`, 제한 없으면 `현재`만 | 원형 화살표 | 남은 턴이 적을 때(규칙값은 CSV) 숫자 깜빡임 2프레임 |
| 5 | 메뉴 | 톱니 | 항상 무채색. 지금의 메뉴 팝업(session 문서 "메뉴") 그대로 |

- 지금 상단에 있는 **유닛 수·점수**는 시안에 없다 → 유닛 수는 정보 패널(6)로, 점수는 메뉴 팝업 머리로 옮기는 안. (확정 필요)
- 숫자는 999에서 표시만 자른다(`999+`). 규칙 상한이 생기면 그 값은 CSV에 둔다.

### 하단 행동 줄 (6~9)
엄지 영역. 왼쪽부터 `[6 ⓘ] [7 펀치] [8 트리] [9 ▶▶  턴 종료 ]`.

- **6 정보**: 정보 패널(지금 선택 시 자동으로 열리는 패널)을 열고 닫는 토글. 아무것도 안 골랐으면 내 종족 요약(유닛 수/수용량, 도시 수).
- **7 신앙 펀치**: 누르면 버튼 위로 스킬 카드가 세로로 쌓여 펼쳐지는 토스트(시안 오른쪽 위 그림).
  - 카드 = `[아이콘] 이름 · 소비 신앙` / `설명 한 줄`. 지금 쓸 수 있는 카드는 `Paper`, 신앙 부족은 `Muted` + 비용 숫자에 취소선 픽셀.
  - 버튼 자체는 "이번 턴 쓸 수 있는 펀치가 1개 이상"일 때만 `Accent` 테두리.
  - 바깥을 누르거나 `Esc`로 닫힘(지금 `Esc` 닫기 순서 유지).
- **8 기술 트리**: 지금 상단 막대의 기술트리 버튼을 내려온다. 연구 가능한 기술이 있으면 우상단 1점 배지(무채색 `Paper` 점).
- **9 턴 종료**: 가장 넓은 버튼, 상태 3가지(시안 오른쪽 아래 체크 3개)를 색 하나로 구분.

| 상태 | 시안 | 표현 |
|---|---|---|
| 행동 남음 | 흰 체크 | `Raised` 바탕 + `Paper` 테두리, 아이콘 ▶▶, 라벨 작게 "남은 행동 n" |
| 행동 없음 | 파란 체크 | **`Accent` 채움** + 아이콘 ▶▶ + 2프레임 숨쉬기(밝기만, 크기 변화 없음) |
| 게임 종료 | 초록 체크 | **`Accent` 채움 + 반전 아이콘(깃발)** + 라벨 "결과 보기" |
| 적 차례 | — | `Base` 바탕, 모래시계 아이콘, 누를 수 없음 |

### PC·모바일 공용
시안은 휴대폰 세로 화면이다. PC에서도 **같은 요소·순서·색·그림**을 쓰고, 두 가지만 따로 고른다.
- **배치는 화면 폭으로** 고른다(지금처럼 `UiKit.CompactWidth` 기준). 휴대폰 가로는 PC와 같은 넓은 배치다.
- **입력 안내는 입력 장치로** 고른다(키보드·마우스가 있으면 PC 안내). 휴대폰 가로에서 단축키 글자가 보이지 않게 하려는 것이다.

| | 좁은 배치(휴대폰 세로) | 넓은 배치(PC·휴대폰 가로) |
|---|---|---|
| 상단 막대 | 1~4 칩이 폭을 나눠 갖고, 5는 오른쪽 끝 | 1~4는 왼쪽 묶음(고정 폭), 5는 오른쪽 끝. 가운데는 비워 지도를 보인다 |
| 하단 행동 줄 | 화면 아래 폭 전체, 9가 남는 폭을 차지 | 오른쪽 열 아래 묶음(열 폭에 맞춤). 6·7·8은 정사각형, 9가 남는 폭 |
| 정보 패널 | 행동 줄 위 아래 시트 | 오른쪽 열(행동 줄 바로 위) |
| 신앙 펀치 카드 | 7 위로 쌓임, 폭 전체 | 7 위로 쌓임, 오른쪽 열 폭 |
| 설명 말풍선 | 누르고 있으면 상단 막대 아래에 | 마우스를 올리면 그 요소 바로 아래에 |

| 입력 | 터치 | 키보드·마우스 |
|---|---|---|
| 강조 | 누르는 동안 1텍셀 내려앉음 | 올리면 `Paper` 테두리, 누르면 1텍셀 내려앉음 |
| 단축키 표시 | 없음 | 버튼 오른쪽 아래 작은 키 글자(`Muted`): 5 `Esc`, 6 `I`, 7 `F`, 8 `T`, 9 `Space` — `Esc`·`F`는 지금 쓰는 키, `I`·`T`·`Space`는 새로 추가(지도 이동 `WASD`·방향키와 겹치지 않음) |

크기는 두 판 모두 UI 단위 그대로다(버튼 최소 크기는 손가락 기준, PC에서는 1280×720 논리 화면이라 상대적으로 작게 보인다). 시안 그림: [모바일](images/hud/mockup_mobile.png), [PC](images/hud/mockup_pc.png) — 원본 `mockups/hud/hud_mockup.html`.

## 5. 픽셀 에셋

- **틀**: `scripts/author_pixel_ui.py`의 Panel·Button·Badge를 유지하고 `ButtonWide`(9 전용, 베벨 2텍셀)와 `Card`(7 토스트)만 추가.
- **아이콘**: 12×12, 1색 실루엣 + 외곽선 1텍셀. `scripts/author_pixel_patterns.py` 패턴으로 그려 [`SpriteCatalog.csv`](spec/csv/sprites.md)에 키 등록(왕관·불꽃·동전·턴·톱니·정보·주먹·트리·▶▶·깃발·모래시계). 아이콘은 무채색으로 그리고 색은 코드에서 토큰으로 물들인다.
- **글꼴**: 지금 Jua(픽셀 아님) → 한글 픽셀 글꼴(예: Galmuri, OFL) 검토. 숫자 전용으로 먼저 바꾸고 본문은 가독성 비교 후 결정.
- **움직임**: 깜빡임·숨쉬기는 2프레임, 0.5초 간격 정도의 계단식. 보간(트윈) 없음.

## 6. 구현 단계

| 단계 | 내용 | 주로 고치는 곳 |
|---|---|---|
| 0 | 색 토큰 도입, 기존 색 상수 치환(화면 변화 최소) | `View/UiKit` |
| 1 | 틀·아이콘·글꼴 에셋 제작, 카탈로그 등록 | `scripts/author_pixel_*.py`, `SpriteCatalog.csv` |
| 2 | 상단 막대 1~5 재배치(한 줄), 유닛 수·점수 이동 | `View/BattleHud.LayoutTopBar` |
| 3 | 하단 행동 줄 6~9, 정보 패널 토글 | `View/BattleHud` |
| 4 | 신앙 펀치 세로 토스트 | `View/FaithPunchHud` |
| 5 | 턴 종료 3상태 + 순위·남은 행동 수 계산 | 계산은 Systems(값 없음, CLAUDE.md 3), 표시만 View |
| 6 | spec·문구 갱신, 화면 캡처 확인 | `docs/spec/game/session.md`, `Strings.csv` `UI.Hud.*` |

- 5단계에 필요한 값: **신앙 순위**(`FaithSystem.RankOf` 재사용, 문구 키 `UI.Hud.FaithRank`), **남은 행동 여부**(지금 "행동을 마친 아군 회색 처리" 판정을 재사용), **턴 제한**(현재 규칙에 없음 → 없으면 `현재`만 표시).
- 검증: 단계마다 Edit Mode RenderTexture 캡처로 PC(1280×720)·가로·세로 3장 비교. 포인트 컬러가 한 화면에 2개를 넘지 않는지 함께 본다.

## 7. 정해야 할 것

1. 상단에서 빠지는 유닛 수·점수의 새 자리.
2. 픽셀 글꼴 도입 범위: 숫자만 / 전체.
3. 턴 제한 규칙을 새로 둘지(둔다면 `GameRules.csv` 키 추가).
