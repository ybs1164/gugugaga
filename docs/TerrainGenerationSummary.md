# 절차적 지형 생성 요약

## 1. 입력
- 바이옴 CSV(`BiomeCsvRow`): 노이즈 설정 + 타일 규칙(`Tiles`) + 구조물 규칙(`Structures`).
- 타일 규칙: 타입(육지/물), Inner/Outer 확률, 최소 개수, 최소 거리, 가장자리 여백, 인접 배제.
- 구조물 규칙: 놓일 수 있는 타일 타입, 확률, 최소 개수, 수도로부터 최대 거리, 물 배치 비율 상한, 무제한 채우기 여부, 인접 배제.

## 2. 타일 생성 — 자유 배치 (Drylands 포함 기본 경로)
1. 바이옴 수만큼 맵을 구역으로 나눠 구역마다 앵커(수도 자리) 하나씩 랜덤 배정.
2. 모든 칸을 가장 가까운 앵커의 바이옴에 배정(Voronoi).
3. 습도 배율을 물 타일 확률/개수에만 적용.
4. 바이옴별 최소 개수를 먼저 채움(거리·인접 제약 지키며).
5. 남은 칸을 Inner/Outer 확률 × 노이즈로 가중 랜덤 채움.

## 3. 타일 생성 — 랜드마스 마스크 (Pangea/Lakes/Continents/Archipelago/Waterworld)
개별 타일 확률만으로는 대륙/호수 같은 공간적 모양이 안 나와서, 모양을 먼저 마스크로 확정한 뒤 위 4~5단계를 얹는다.
1. 중심점(프리셋마다 개수 다름) 기준 방사형 감쇠 + 노이즈로 칸마다 점수 매기고, 점수 상위 칸을 목표 물 비율만큼 육지로 확정.
2. 앵커가 물 칸이면 가장 가까운 육지로 이동.
3. 물로 확정된 칸은 거리 제약 없이 바로 물 타일로 채움(바다가 끊기지 않게).
4. 육지로 확정된 칸만 위 자유 배치의 4~5단계로 채움.

| 프리셋 | 중심점 | 특징 |
|---|---|---|
| Pangea | 1개(중앙) | 중앙 대륙 + 외곽 바다 |
| Lakes | 0개(노이즈만) | 흩어진 호수, 테두리는 항상 육지 |
| Continents | 바이옴 수만큼 | 대륙 여러 개로 분리 |
| Archipelago | 바이옴 수만큼(노이즈 비중↑) | 흩어진 작은 섬 |
| Waterworld | 바이옴 수만큼(앵커 보호) | 거의 전부 물, 수도 주변만 육지 |

## 4. 구조물 생성 (타일 생성 이후)
1. 바이옴 앵커마다 수도 자동 배치.
2. 바이옴별 구조물 규칙마다 목표 개수 계산 후, 조건(허용 타일/거리/인접) 맞는 빈 칸에 확률 비례로 배치.
3. 사방이 물로 막힌 고립 칸을 육지로 바꿔 외딴 섬 마을 배치(맵 크기별 개수 고정).

## 5. Sandbox UI
- 맵 크기, 습도(=랜드마스 모드 + 물 비율) 버튼으로 선택 → "지형 생성" 클릭 시 타일 생성 → 구조물 생성 → 화면 갱신 순으로 실행.

## 6. 검증
- Unity CLI 배치모드 자동 테스트로 제약 준수, 개수/비율, 시드 재현성, 프리셋별 모양 특징을 PASS/FAIL로 확인.
