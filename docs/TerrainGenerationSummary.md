# 절차적 지형 생성 요약

이 프로젝트의 맵 생성 파이프라인을 한 장으로 정리한 문서. 규칙의 근거는
[`PolytopiaMapGeneration.md`](PolytopiaMapGeneration.md)(Polytopia 위키 요약), CSV 작성법은
[`BiomeCsvSandbox.md`](BiomeCsvSandbox.md)에 있다.

## 한눈에 보기

```
[입력] 바이옴 CSV + 맵 크기 + 맵 타입(습도) + 시드
   │
   ├─ TerrainGenerationSystem.Generate ─────────────────────────────────────────
   │   1. 수도 위치        쿼드런트 맵: 구역마다 1개 / Pangea·Continents: 땅을 만든 뒤
   │   2. 지형 전 마을     Suburb(Lakes·Archipelago), Pre-terrain(Lakes·Archipelago·Waterworld)
   │   3. 땅 모양          Drylands: 타일 확률 / 나머지: 랜드마스 마스크(Continents는 대륙 성장)
   │   4. 타일 채우기      최소 개수 → Inner/Outer 가중치 × 노이즈
   │   5. 숲/산 레이어     산 14%·숲 38%(배수 적용) 쿼터
   │   6. 물 깊이 분류     육지 옆 = 얕은 물, 나머지 = Ocean(깊은 바다)
   │
   └─ StructureGenerationSystem.Generate ───────────────────────────────────────
       1. 수도 + 지형 전 마을 배치
       2. Post-terrain 마을 포화 → 외딴 섬 마을 → (Lakes) 육지 다리로 연결 보장
       3. 물 깊이 재분류(2단계가 지형을 바꿨을 수 있음)
       4. 등대: 맵 네 모서리
       5. 자원: 모든 도시 2칸 이내, Inner/Outer 비율 쿼터
       6. 유적(맵 크기별 고정 개수) → 불가사리(물 25칸당 1개)
   │
[출력] GridWorld(지형/타일/구조물) → GridView가 렌더링
```

## 필수 구성요소 체크리스트

| 요소 | 역할 | 이 프로젝트의 구현 |
|---|---|---|
| 시드/재현성 | 같은 입력이면 항상 같은 결과 | `System.Random(seed)` 하나로 지형·구조물 전체 고정 |
| 노이즈 함수 | 유기적인 패턴 | `NoiseSystem.Sample`(프랙탈 Perlin, 0~1, `seedOffset`으로 독립 필드) |
| 입력 규칙 | 무엇을 어떻게 생성할지 | 바이옴 CSV(타일 규칙 + 구조물 규칙 + 숲/산 배수) |
| 매크로 구조 | 맵을 큰 덩어리로 나눔 | 수도(쿼드런트/farthest-point) + Voronoi 바이옴 배정, 랜드마스 마스크 |
| 마이크로 구조 | 칸 단위 규칙 위반 방지 | 최소 거리, 가장자리 여백, 인접 배제(구조물은 8방향) |
| 확률적 선택 | 같은 규칙에서도 다양한 결과 | 타일: Inner/Outer 가중치 × 노이즈 / 자원: 비율 쿼터 + 확률적 반올림 |
| 밀도/개수 제어 | 맵 크기에 맞는 양 | 쿼터(숲/산/자원), 맵 크기표(유적/외딴 섬 마을), 칸당 개수(불가사리) |
| 출력 | 게임 데이터로 기록 | `GridWorld`의 Terrain/TileTypeId/StructureId |
| 검증 | 규칙대로 동작하는지 | CLI 배치모드 자동 테스트(PASS/FAIL) — 아래 7절 |

## 1. 입력
- **바이옴 CSV**(`BiomeCsvRow`): 행 하나 = 바이옴 하나 = 플레이어(수도) 하나. 노이즈 설정, 타일 규칙(`Tiles`),
  구조물 규칙(`Structures`), 숲/산 배수(`MountainRate`/`ForestRate`).
- **맵 크기**: 11/14/16/18/20/30 정사각형.
- **맵 타입(습도 프리셋)**: 이름과 목표 물 비율 — Drylands 0.05, Lakes 0.275, Continents 0.55, Pangea 0.50,
  Archipelago 0.70, Waterworld 0.95.

## 2. 수도와 지형 전 마을 (TerrainGenerationSystem)

| 맵 타입 | 수도 | Suburb | Pre-terrain 마을 | 본토 마을(지형 전) |
|---|---|---|---|---|
| Drylands | 쿼드런트 | ✕ | ✕ | ✕ |
| Lakes / Archipelago | 쿼드런트 | 수도마다 2개 시도 | (⌊가로/3⌋² − 도시 수) × 0.3 | ✕ |
| Waterworld | 쿼드런트 | ✕ | (⌊가로/3⌋² − 도시 수) × 0.1 | ✕ |
| Pangea / Continents | 땅을 만든 뒤 farthest-point | ✕ | ✕ | 포화 배치(Continents는 대륙마다 최소 1개) |

- **쿼드런트**: 바이옴 1~4개 → 2x2, 5~9개 → 3x3, 10~16개 → 4x4 구역. 서로 가장 먼 구역부터 채우고, 구역 중심부에서만
  뽑으며, 가장자리 2칸 이상 + 수도끼리 3칸 이상.
- **Pangea/Continents 수도**: 가장자리 2칸 이상 + 9칸 이상 육지 덩어리 위에서, 여러 번 시도해 수도 간 최소 거리가
  가장 큰 조합. 해안 선호, Continents는 가능하면 서로 다른 대륙.
- **도시 간격**: Suburb/Pre-terrain 마을은 다른 도시와 거리 2 이상(바로 옆 금지), 본토 마을은 거리 3 이상.
- 수도 3x3과 모든 사전 마을 칸은 **반드시 육지**가 된다(목표 물 비율보다 우선). 마스크 컷에서 떨어지면 가장 가까운
  육지로 옮기고, 옮기다 다른 도시와 붙으면 버린다.

## 3. 땅 모양

**Drylands(Freeform)**: 마스크 없이 타일 확률로 채운다. 습도 배율은 물 타일의 가중치/개수에만 적용.

**랜드마스 마스크(나머지)**: 칸마다 "육지 점수"를 매겨 상위 (1−물 비율)만 육지로 확정 → 목표 물 비율을 정확히 맞춘다.

| 맵 타입 | 방식 | 특징 |
|---|---|---|
| Pangea | 중앙 1점 방사형 감쇠 + 노이즈 | 중앙 대륙 + 외곽 바다 |
| Lakes | 노이즈만, 테두리 칸에 큰 보너스 | 흩어진 호수, 테두리는 항상 육지 |
| Archipelago | 바이옴 수만큼의 중심점 + 노이즈 비중↑ | 조각난 섬 |
| Waterworld | 바이옴 수만큼의 중심점 | 거의 물, 도시 자리만 육지 |
| Continents | **대륙 성장**(아래) | 서로 떨어진 대륙 |

**Continents 대륙 성장**: 대륙 수 = 플레이어 수를 기본으로, 대륙 하나가 30~200칸이 되도록 목표 육지 면적으로 제한.
씨앗을 서로 최대한 멀리 뽑고, 라운드 로빈으로 노이즈 점수가 가장 높은 경계 칸을 하나씩 붙인다. **다른 대륙과
8방향으로 닿는 칸은 붙이지 않아** 대륙 사이에 항상 물이 1칸 이상 있다(원문의 "강").

## 4. 타일 채우기와 숲/산
1. 수도로 Voronoi 바이옴 배정(칸마다 가장 가까운 수도의 바이옴).
2. 바이옴별 최소 개수(`MinCount`/`CountPerTiles`) 우선 배치.
3. 나머지 칸: Inner/Outer 가중치 × 노이즈로 가중 랜덤. Inner = 가장 가까운 도시(수도 + 사전 마을)까지 `InnerRadius` 이내.
4. 숲/산 레이어: 바이옴마다 도시 칸을 뺀 육지의 산 14%×배수, 숲 38%×(100%−산%)/86%×배수를 정확히 쿼터로.
5. 물 깊이 분류: 상하좌우 4방향에 육지가 있는 물 = 바이옴 물 타일(얕은 물), 없으면 `Ocean`.

## 5. 구조물 (StructureGenerationSystem) — 원문 순서대로 단계별
1. **수도 + 사전 마을** 배치.
2. **Post-terrain 마을**: 맵 전체를 셔플된 순서로 한 번 훑으며 CSV `Village` 규칙(허용 타일/가장자리 2칸/도시 간격 3)을
   만족하는 칸마다 배치 → 자리가 없을 때까지.
   - **외딴 섬 마을**(Pangea/Continents/Waterworld): 8방향이 전부 물인 칸을 육지로 바꿔 마을 배치, 맵 크기별 0/1/2/3/4/9개.
   - **Lakes 연결 보장**: 수도마다 4방향 육로로 닿는 마을이 2개 미만이면, 가장 가까운 바깥 마을까지 최단 경로의 물을
     육지로 바꿔 "육지 다리"를 놓는다.
3. **물 깊이 재분류**(섬/다리로 바뀐 해안 반영).
4. **등대**: 네 모서리(자원보다 먼저 놓아 항상 4개).
5. **자원**: 모든 도시로부터 거리 1(Inner)/2(Outer)인 칸을 (바이옴, Inner/Outer, 타일)별로 묶고 CSV 자원 비율만큼 쿼터로
   채운다. 기본값: 과일·작물 37.5%/12.5%(평지), 사냥감 50%/15.8%(숲), 광물 78.6%/21.4%(산), 물고기 50%(얕은 물).
6. **유적 → 불가사리**: 유적은 맵 크기별 4/5/7/9/11/23개, 불가사리는 물 25칸당 1개. 인접 배제는 8방향(유적: 도시·유적,
   불가사리: 도시·등대·불가사리). Lakes 맵에서만 물 위 유적 최대 1/3.

## 6. Sandbox UI
- 맵 크기/습도 버튼으로 선택 → "지형 생성" 클릭 → 지형 생성 → 구조물 생성 → 화면 갱신(구조물 단계가 지형을 바꿀 수
  있어서 지형 표시는 구조물까지 끝난 뒤에 갱신).
- 구조물 위에 마우스를 올리면 이름/설명 패널.

## 7. 검증 (Unity CLI 배치모드)
```
unity run . -- -nographics -executeMethod TacticsECS.EditorTools.TerrainGenerationVerification.Run
unity run . -- -nographics -executeMethod TacticsECS.EditorTools.StructureGenerationVerification.Run
```
- **지형**: CSV 왕복, 단일 바이옴 제약, 시드 재현성, 쿼드런트 공정성, 습도 배율, 맵 타입별 물 비율/모양, 사전 마을
  계획, 사전 마을 칸 육지 보장, 수도 배치 규칙(396맵), 도시 인접 금지, 숲/산 쿼터, 물 깊이 분류, Continents 모양(대륙
  분리/200칸 이하/모든 대륙에 도시).
- **구조물**: 수도 위치, 허용 타일/거리, 시드 재현성(전 맵 타입), 자원이 모든 도시 주변(수도 옆 포함)에만, Inner/Outer
  쿼터, 8방향 인접 배제, 마을 포화, Lakes 유적 물 비율, 유적 개수표, 등대(항상 4개), 샘플 CSV 전 맵 타입 규칙 점검, 외딴 섬 마을
  (Continents/Waterworld)과 게이팅, Lakes 육로 연결.
