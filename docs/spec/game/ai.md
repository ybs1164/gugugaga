# AI

수치: [`GameRules.csv`](../csv/game-rules.md) `AI.*`. 코드: `EconomyAI`(경제), `EnemyAI`(군사). 규칙 기반이며 어느 팀이든 돌릴 수 있다(헤드리스 시뮬레이션은 양쪽 모두 AI).
AI도 플레이어와 같은 규칙·시야를 따른다 — 구름 속 적과 정착지는 모른다.

## 한 턴의 순서
1. **경제** (`EconomyAI`)
   1. 정착지 위에서 턴을 시작한 유닛은 점령, 유적 위 유닛은 탐험, 불가사리 위 배는 인양.
   2. 밀린 레벨업 보상 선택(상황별).
   3. 연구 가능한 기술 중 가장 싼 것 하나 연구.
   4. 위협(보이는 적이 자기 도시 `AI.ThreatRadius` 안)이 있으면 훈련 먼저, 없으면 건설 먼저.
   5. 건설: 달성한 기념물 → 수도 연결 도로·다리(`AI.MaxConnectionBudget` 이내) → 별당 가치가 높은 순. 한 턴 최대 `AI.MaxImprovementsPerTurn`회.
   6. 자기 영토의 뗏목을 살 수 있는 가장 좋은 배로 업그레이드.
2. **군사** (`EnemyAI`, 유닛마다)
   1. 사거리 안에 보이는 적이 있으면 공격하고 끝.
   2. 목표 선택: 점령 대기 → 도시 방어 복귀(적이 도시 `AI.DefendRadius` 안) → 가장 가까운 적·점령 목표 → (배) 불가사리 → 구름 가장자리 탐험.
   3. 목표까지 여행 거리가 가장 짧은 칸으로 이동. 바다 건너면 항구에서 배를 탄다.
   4. 이동 후 사거리 안에 적이 있으면 공격.

## 공격 대상 고르기
처치 가능한 대상 우선, 아니면 (준 피해 − 받을 반격의 절반)이 큰 대상. 처치하지 못하는데 반격에 죽는 공격은 하지 않는다.

세부(가치 계산, 여행 거리 BFS, 보상 선택 조건): 각 클래스 주석.
