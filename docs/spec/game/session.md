# 한 판 흐름·저장·화면

빠른 한 판(`Assets/Scenes/Mobile.unity`, `BattleController` `quickPlay`)의 시작부터 끝까지와 저장, 그리고 PC·모바일 공용 전투 화면 배치.
코드: `BattleController`(흐름·저장 시점), `SaveSystem`·`GraphSerializer`(파일), `View/TitleHud`, `View/BattleHud`, `View/TechTreeHud`, `View/FaithPunchHud`, `View/BattleCutIn`. 문구: [`Strings.csv`](../csv/strings.md) `UI.Title.*`, `UI.Menu.*`, `UI.Result.*`, `UI.Hud.*`, `UI.Guide.*`, `UI.CutIn.*`.
샌드박스·데모 씬의 전투도 같은 화면을 쓴다. 시작 화면과 저장은 빠른 한 판에만 있다.

## 시작 화면
- **이어하기**: 저장이 있을 때만 켜지고, 버튼 오른쪽에 그 판의 플레이어 종족과 턴이 보인다. 누르면 저장한 판으로 바로 돌아간다.
- **새로하기** → 종족 고르기: 종족 카드(아이콘 + 이름, 맨 앞 **무작위**)에서 고르면 설명과 시작 조건 요약([tribe](tribe.md))이 보이고, **시작**으로 판을 연다.
  - 카드 아래 **신** · **맵** · **난이도** 세 줄: 줄마다 고를 수 있는 것이 모두 나와 있고 고른 것이 포인트 색이다. 신은 아이콘(맨 앞 무작위, 그 뒤 [`Gods.csv`](../csv/gods.md) 순서 — 고른 신의 설명이 상세 글 끝에 붙는다), 맵은 크기 프리셋(`BattleController.MapSizePresets`)이고 처음 값은 아래 "판 시작"의 기본 크기다. 난이도는 상대 AI의 [난이도](ai.md#난이도)([`AIDifficulty.csv`](../csv/ai-difficulty.md) 순서, 처음 값은 `AI.DefaultDifficulty`·그 뒤로는 마지막에 고른 것)이고 고른 난이도의 설명이 상세 글 끝에 붙는다.
  - 종족·신 아이콘은 [HUD 그림](../csv/sprites.md#hud-그림)의 `Tribes/<Id>`·`Gods/<Id>`(없으면 `random`).
- **언어**: 버튼 오른쪽에 지금 언어. 누르면 다음 언어로 바꾸고 화면을 다시 연다.
- **표 가져오기** · **기본 표**: 아래 [표 팩](#표-팩). 버튼 오른쪽에 지금 쓰는 표(기본 표, 또는 팩 이름·ID와 읽기 경고 수)가 보인다.

## 판 시작
- 맵: 종족 고르기에서 고른 크기 프리셋(기본은 씬의 `gridWidth`에 가장 가까운 것), 맵 타입은 기본값 — [map](map.md).
- 플레이어 종족·신은 고른 것(무작위면 판마다), 상대 종족은 가능하면 플레이어와 다른 무작위, 상대 신은 무작위([faith](faith.md)).
- 지형을 만든 뒤 바로 1턴. 카메라는 내 수도를 비추고, 한 칸이 화면에서 `UiScale.MinTileInches` 이상이 되게 확대한다(PC처럼 맵 전체를 담아도 칸이 충분히 크면 맵 전체).

## 승패
- 섬멸: [turn](turn.md#승패). 신앙 승리: [faith](faith.md#신앙-승리). 턴 제한은 없다.
- 끝나면 결과 창(승리/패배, 이유, 턴, 점수)이 뜬다: **새 게임**(종족 고르기부터) · **메인 화면** · **지도 보기**(창만 닫는다. 메뉴에서 다시 새 게임). 샌드박스·데모는 **다시 시작**.

## 저장·이어하기
- 저장 파일은 표마다 하나다: 기본 표는 `Application.persistentDataPath/quickplay.sav`, 표 팩은 `quickplay-<팩 ID>.sav`. 표를 바꿔도 다른 표의 저장은 지워지지 않는다. 판의 데이터 전부(맵·유닛·도시·기술·신앙·과업)와 턴, 종족·신, 카메라 위치를 그대로 담는다.
- 저장하는 때: 내 턴이 시작될 때(턴 시작 수입 등을 반영한 뒤), 앱이 백그라운드로 갈 때·꺼질 때, 메뉴의 **메인 화면**·언어 바꾸기 직전. 상대 턴 도중에는 저장하지 않는다 — 그 턴을 시작한 시점의 저장이 남는다.
- 판이 끝나면 저장을 지운다(끝난 판은 이어할 수 없다). 새 게임을 시작하면 그 판의 첫 턴 저장이 덮어쓴다.
- 이어하기는 게임 규칙을 다시 실행하지 않고 데이터를 그대로 되살린 뒤 화면만 다시 그린다. 저장 형식이 바뀌면(`SaveSystem.Version`) 옛 저장은 읽지 않는다.

## 표 팩
다른 PC의 Sandbox에서 쓰던 표를 이미 설치된 앱(휴대폰·PC 빠른 한 판)에서 그대로 쓴다. 형식: [table-pack](../csv/table-pack.md).
- 내보내기(Sandbox 툴바 **팩 내보내기**): 지금 쓰는 표 전부를 zip 하나로 저장한다. 상태 줄에 팩 이름·ID·표 수가 뜬다.
- 가져오기(시작 화면 **표 가져오기**): 안드로이드는 시스템 파일 고르기, PC는 파일 열기 창으로 zip을 고른다. 매니페스트와 표마다 해시가 맞으면 `Application.persistentDataPath/TablePack/`에 풀고 화면을 다시 연다. 하나라도 틀리면 아무것도 바꾸지 않고 이유를 보인다.
- 팩이 있으면 빠른 한 판은 기본 표 대신 그 폴더를 읽는다. 팩에 없는 표는 기본 표, 팩의 `Strings.csv`에 없는 키는 기본 번역 표에서 채운다(옛 빌드에서 내보낸 팩). 이 앱이 모르는 표는 풀지 않는다.
- **기본 표**: 가져온 팩을 지우고 화면을 다시 연다.
- 샌드박스·데모 씬은 팩을 읽지 않는다.

## 메뉴
오른쪽 위 **메뉴** 또는 `Esc`(안드로이드 뒤로 가기) — 창 머리에 점수(`UI.City.ScoreLine`): **계속하기** · **새 게임**(진행 중이면 한 번 묻는다) · **메인 화면**(저장하고 시작 화면으로) · **언어**. 샌드박스·데모는 새 게임·메인 화면 대신 **다시 시작**.
`Esc`는 가장 위에 열린 것부터 닫는다: 대화 상자 → 신앙 펀치 → 기술 트리 → 정보 패널 → (아무것도 없으면) 메뉴. 레벨업 보상 창은 닫히지 않는다.

## 화면 배치
PC와 휴대폰(가로·세로)이 같은 화면을 쓴다. 크기는 UI 단위이고, 화면 픽셀로의 배율은 [UI 해상도](../csv/sprites.md#ui-해상도) 규칙을 따른다 — 그래서 논리 화면은 PC(1080p) 1280x720, 휴대폰 가로 약 900x400, 세로 약 430x960이고 버튼은 손가락 크기(약 7mm) 이상이다. 모든 화면은 안전 영역(카메라 구멍·제스처 바 제외) 안에 놓인다.
배치는 안전 영역 폭으로 고른다: 폭이 `UiKit.CompactWidth` 이상이면 넓은 배치, 좁으면(휴대폰 세로) 좁은 배치. 화면을 돌리면 그 자리에서 다시 배치한다.

| | 넓은 배치 | 좁은 배치 |
|---|---|---|
| 상단 칩 | 왼쪽부터 순위 · 신앙 · 별 · 턴, 오른쪽 끝 메뉴 | 같다 |
| 행동 줄(신앙 펀치 · 기술 · 턴 종료) | 오른쪽 아래, 오른쪽 열 폭 | 아래, 화면 폭 전체 |
| 정보 패널·신앙 펀치 | 오른쪽 열 | 아래 시트(폭 전체, 화면 절반까지) |
| 길잡이 | 왼쪽 아래 | 상단 칩 바로 아래(알림은 그 밑) |
| 종족 고르기 | 왼쪽 위 카드 4열, 왼쪽 아래 선택 줄, 오른쪽 상세 | 위에서부터 카드 2열 · 선택 줄 · 상세 |
| 설명 말풍선 | 왼쪽 아래 | 상단 막대 아래 |
| 기술 트리의 상세 | 오른쪽 열 | 아래 띠 |

- 모양: 흰 평면 카드에 짙은 글자 두 톤이고 포인트 색은 하나(`UiKit.PrimaryColor`) — 지금 쓸 수 있는 신앙 펀치, 1위 순위 아이콘, 가득 찬 신앙 게이지, 고른 선택지, 대화 상자의 기본 버튼에만 쓴다. 누르는 것은 모두 높이 `UiKit.TouchSize`, 간격은 묶음 안 `UiKit.ItemGap`·화면 가장자리 `UiKit.Gap`. 글꼴은 본문 `HudArt.Body`, 숫자 `HudArt.Number`(도트). 아이콘은 한 벌([HUD 그림](../csv/sprites.md#hud-그림)) — 기술·패시브 배지만 [도트 아이콘 표](../csv/sprites.md#visualid-접두사)를 쓴다.
- 상단 칩: 아이콘 + 숫자. 순위는 [신앙 순위](faith.md)(1위일 때만 아이콘이 포인트 색), 신앙은 현재 값(크게)과 최대·턴당 수입(작은 회색), 칩 바닥의 게이지(누르면 신앙 펀치), 별은 가진 별과 턴당 수입(작은 회색), 턴은 내 턴이면 번호만·적 턴이면 짙은 칩에 `UI.Hud.EnemyTurn`. 좁은 배치에서는 수입을 뺀다. 오른쪽 끝 **메뉴**는 톱니 아이콘. 대신전이 있으면 칩 아래 오른쪽에 진행 상태. 점수는 메뉴 창에 보인다.
- 행동 줄: **신앙 펀치**(주먹 아이콘 + 지금 쓸 수 있는 펀치 수, 하나라도 있으면 포인트 색) · **기술**(아이콘) · **턴 종료**(아이콘).
- 길잡이: 게임 속 유닛이 아닌 안내 캐릭터(그림 [HUD 그림](../csv/sprites.md#hud-그림) `Guide/guide` — 없으면 말풍선만). 말풍선 한 줄(`UI.Guide.*`)로 지금 할 일을 알려 준다: 고를 유닛이 남았는지, 고른 유닛이 공격·이동할 수 있는지, 신앙 펀치의 어느 단계인지, 보상을 골라야 하는지, 상대 차례인지. 유닛 정보(정보 패널)와는 따로 있다. 시작 화면·결과 뒤·샌드박스 배치 단계에는 나오지 않는다.
- 정보 패널: 고른 유닛(이름, 소속·베테랑 진행, 체력 막대와 현재/최대 체력 — 현재는 크게·최대는 작은 회색, 공격·방어·이동·사거리, 패시브 배지)이나 칸·도시(구조물, 도시 정보, 과업)와, 지금 할 수 있는 행동을 한 목록으로(방어·치유·자폭·대기·기도, 점령·탐험·해산·업그레이드, 훈련·보상·건설). 유닛 행동에는 아이콘이 붙는다. 못 하는 행동은 이유와 함께 흐리게. 길면 스크롤. 닫기 버튼은 없다 — 지도의 빈 곳을 누르거나 `Esc`로 선택을 푼다.
- 레벨업 보상 창: 내 턴에 고르지 않은 [레벨업 보상](city.md#레벨업-보상)이 생기면 가운데 창이 뜨고, 하나를 골라야 닫힌다(`Esc`·바깥 누르기로 닫히지 않는다).
- 지도 위 유닛 행동 표시(규칙은 [unit](unit.md)·[combat](combat.md)·[movement](movement.md), 화면만 바꾼다):
  - 고른 아군: 그 칸에 노란 테두리, 갈 수 있는 칸은 파란 테두리, 칠 수 있는 대상(공격·침투·약탈·폭우)은 빨간 테두리. 신앙 펀치의 범위는 포인트 색 테두리, 그 안에서 효과를 받을 유닛은 빨간 테두리. 칸을 색으로 덮지 않는다.
  - 체력: 유닛 머리 위 `UnitView.HpPips`칸 막대 하나(숫자 없음). 칸 색이 팀(아군 파랑·적 빨강)이고 남은 체력 비율만큼 칸이 찬다(살아 있으면 한 칸 이상). 베테랑은 막대에 금색 테두리. 정확한 숫자는 정보 패널에서 본다.
  - 이동: 경로 탐색이 고른 칸을 하나씩(상하좌우로) 밟으며 칸마다 한 번 통통 뛴다. 적 유닛도 같다 — 적 턴에는 이동이 다 끝난 뒤 공격이 이어진다.
  - 공격: [전투 컷인](#전투-컷인)이 먼저 나오고, 끝나면 지도에서 짧게 한 번 더 — 공격자가 대상 쪽으로 찌르고 → 대상에 흰 피해 숫자 → 반격이 있으면 잠깐 뒤 대상이 되찌르고 공격자에 피해 숫자. 적 턴의 공격도 이동이 끝난 뒤 하나씩 이 순서로 보인다(플레이어가 볼 수 있는 칸의 공격만 컷인).
  - 스플래시·짓밟기: 주변 유닛의 피해 숫자는 주 대상과 같은 순간(짓밟기는 이동 직후)에 함께 뜨고, 로그에 `UI.Log.Splash` 줄이 남는다.
  - 체력 막대는 맞기 전 값에 머물다가 피해 숫자가 뜨는 순간 줄어든다(적 턴도 공격을 하나씩 보여줄 때). 처치된 유닛은 자기 피해 숫자가 뜬 뒤 깜빡이며 사라진다. 치유·대기 회복은 초록 `+N`.
  - 이번 턴 더 할 수 있는 행동이 없는 아군(행동을 마쳤고 더 움직일 수 없음, 빙결 포함)은 회색으로 어두워진다. 내 턴이 시작되면 돌아온다.
  - 행동 화면 녹화: [README](../../../README.md#실행) "유닛 행동 GIF".
- 칩 아래 왼쪽 알림(가장 최근 행동 기록이 떴다가 사라진다), 가운데 대화 상자(화면 폭에 맞춘다).
- 지도: 끌어서(마우스 왼쪽·한 손가락) 옮기고 휠·두 손가락 핀치로 확대한다. 시작 화면·기술 트리·대화 상자가 열려 있으면 지도는 움직이지 않고, 패널 위의 휠은 그 목록을 스크롤한다.
- 기술 트리: 전체 화면 창. 가운데 허브에서 갈래가 방사형으로 뻗고 티어마다 바깥 원(2티어부터는 갈래 안에서 좌우로 갈라진다). 나무는 끌어서 옮기고 휠·핀치로 확대한다(나무 가장자리가 창 가운데까지 온다). 열 때와 창 크기가 바뀔 때 허브를 가운데로, 나무가 들어가는 배율로 맞추되 노드가 너무 작아지지 않게 하한을 둔다 — 휴대폰에서는 바깥 원이 화면 밖에 있어 끌어서 본다.
- 휴대폰은 가로·세로 모두 쓴다(자동 회전, 빌드 설정 — [README](../../../README.md#실행)).

## 전투 컷인
공격 한 번마다 화면 가운데 띠(`BattleCutIn.BandHeight`)에 공격자(왼쪽)와 대상(오른쪽)이 선다. 판정이 끝난 결과를 보여 줄 뿐 규칙은 [combat](combat.md) 그대로다. 화면을 누르거나 `Esc`로 건너뛴다. 결과·보상 창은 컷인이 끝난 뒤에 보인다.
- 배율: 배경과 유닛이 같은 배율(그림 1픽셀 = `BattleCutIn.Px` UI 단위)이다. 유닛을 따로 키우지 않는다. 낮은 화면(휴대폰 가로)에서는 띠 전체를 한 단계 작은 배율로 그려 위아래 판이 화면에 들어가게 한다.
- 배경: 비스듬한 경계의 왼쪽은 공격자가 선 칸, 오른쪽은 대상이 선 칸 — 도시 · 평지 · 숲 · 산 · 얕은 물 · 깊은 바다([HUD 그림](../csv/sprites.md#hud-그림) `CutIn/*`).
- 띠 위: 피해와 반격 숫자(반격이 있으면 빨강). 띠 아래 양쪽: 이름(적은 빨강), 팀 색 체력 막대와 현재/최대, 선 칸 이름. 대상 쪽에는 위치 방어 배수 꼬리표(`UI.CutIn.Defense`·`UI.CutIn.Wall`). 길잡이는 나오지 않는다.
- 순서: 띠가 열린다 → 공격 → 대상 머리 위에 흰 피해 숫자와 체력 막대 감소 → (반격이 있으면) 대상이 되받아치고 공격자에 빨간 숫자 → 띠가 닫힌다. 처치된 쪽은 깜빡이며 사라진다.
- 두 유닛의 속성에 따라 달라지는 것(효과는 흰 점·선과 짧은 꼬리표뿐):

| 속성 | 연출 |
|---|---|
| 근접(붙어 있는 대상) | 대상 앞까지 달려들고, 흰 점 한 줄이 베는 자리를 긋는다 |
| 원거리(두 칸 이상) | 더 벌려 서서 제자리에서 쏘고, 흰 탄이 경계를 넘어간다 |
| 돌격(이동 뒤 공격) | 달려드는 동안 뒤로 속도선 세 줄 |
| 비행 | 위에서 비스듬히 내리꽂는다 |
| 스플래시·짓밟기 | 대상 둘레에 흰 테두리, 주변 유닛의 작은 피해 숫자가 같은 순간에 뜬다 |
| 빙결 · 중독 · 전향 | 대상이 하늘색 · 보라색 · 공격자 팀 색으로 물들고 꼬리표(`UI.CutIn.Frozen`·`Poisoned`·`Converted`) |
| 방어 태세 | 대상 앞에 방패 표식, 피해 숫자가 작다 |
| 위치 방어(숲·산·물·도시) | 맞을 때 잎·돌·물방울 조각이 튄다. 피해 숫자가 작다 |
| 성벽 | 대상 앞에 벽이 서고 벽돌 조각이 튄다 |
| 배에 탄 유닛 | 발밑에 물결 두 줄 |
| 큰 유닛(최대 체력 `BattleController.BigUnitHp` 이상)·큰 피해 | 띠가 흔들리고 숫자가 크다 |
| 반격하지 못함(매복·경직·사거리 밖) | 꼬리표 `UI.CutIn.NoCounter` |
| 처치 | 꼬리표 `UI.CutIn.Defeated`, 콤보 유닛이면 `UI.CutIn.Again` |
| 큰 반격(공격자 체력의 절반 이상) | 반격 직전 잠깐 멈추고 띠에 빨간 테두리 |
