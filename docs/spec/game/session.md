# 한 판 흐름·저장·화면

빠른 한 판(`Assets/Scenes/Mobile.unity`, `BattleController` `quickPlay`)의 시작부터 끝까지와 저장, 그리고 PC·모바일 공용 전투 화면 배치.
코드: `BattleController`(흐름·저장 시점), `SaveSystem`·`GraphSerializer`(파일), `View/TitleHud`, `View/BattleHud`, `View/TechTreeHud`, `View/FaithPunchHud`. 문구: [`Strings.csv`](../csv/strings.md) `UI.Title.*`, `UI.Menu.*`, `UI.Result.*`, `UI.Hud.*`.
샌드박스·데모 씬의 전투도 같은 화면을 쓴다. 시작 화면과 저장은 빠른 한 판에만 있다.

## 시작 화면
- **이어하기**: 저장이 있을 때만 켜지고, 그 판의 플레이어 종족과 턴이 아래에 보인다. 누르면 저장한 판으로 바로 돌아간다.
- **새로하기** → 종족 고르기: 왼쪽 목록(맨 앞 **무작위**)에서 고르면 오른쪽에 설명과 시작 조건 요약([tribe](tribe.md))이 보이고, **시작**으로 판을 연다.
  - 시작 버튼 위 **신**·**맵 크기** 버튼: 누를 때마다 다음 값으로 넘어간다. 신은 무작위 → [`Gods.csv`](../csv/gods.md) 순서(고른 신의 설명이 상세 글 끝에 붙는다), 맵 크기는 크기 프리셋(`BattleController.MapSizePresets`) 순서이고 처음 값은 아래 "판 시작"의 기본 크기다.
- **언어**: 다음 언어로 바꾸고 화면을 다시 연다.
- **표 가져오기** · **기본 표**: 아래 [표 팩](#표-팩). 버튼 아래 줄에 지금 쓰는 표(기본 표, 또는 팩 이름·ID와 읽기 경고 수)가 보인다.

## 판 시작
- 맵: 종족 고르기에서 고른 크기 프리셋(기본은 씬의 `gridWidth`에 가장 가까운 것), 맵 타입은 기본값 — [map](map.md).
- 플레이어 종족·신은 고른 것(무작위면 판마다), 상대 종족은 가능하면 플레이어와 다른 무작위, 상대 신은 무작위([faith](faith.md)).
- 지형을 만든 뒤 바로 1턴. 카메라는 내 수도를 비추고, 한 칸이 화면에서 `UiScale.MinTileInches` 이상이 되게 확대한다(PC처럼 맵 전체를 담아도 칸이 충분히 크면 맵 전체).

## 승패
- 섬멸: [turn](turn.md#승패). 신앙 승리: [faith](faith.md#신앙-승리). 턴 제한은 없다.
- 끝나면 결과 창(승리/패배, 이유, 턴, 점수)이 뜬다: **새 게임**(종족 고르기부터) · **메인 화면** · **지도 보기**(창만 닫는다. 메뉴에서 다시 새 게임). 샌드박스·데모는 **다시 시작**.

## 저장·이어하기
- 저장 파일은 표마다 하나다: 기본 표는 `Application.persistentDataPath/quickplay.sav`, 표 팩은 `quickplay-<팩 ID>.sav`. 표를 바꿔도 다른 표의 저장은 지워지지 않는다. 판의 데이터 전부(맵·유닛·도시·기술·신앙·과업)와 턴, 종족·신, 카메라 위치를 그대로 담는다.
- 저장하는 때: 내 턴이 시작될 때(턴 시작 수입 등을 반영한 뒤), 앱이 백그라운드로 갈 때·꺼질 때, 메뉴의 **메인 화면**·언어 바꾸기 직전. 상대 턴 도중에는 저장하지 않는다 — 그 턴을 시작한 시점의 저장이 남는다.
- 판이 끝나면 저장을 지운다(끝난 판은 이어할 수 없다). 새 게임을 시작하면 그 판의 첫 턴 저장이 덮어쓴다.
- 이어하기는 게임 규칙을 다시 실행하지 않고 데이터를 그대로 되살린 뒤 화면만 다시 그린다. 저장 형식이 바뀌면(`SaveSystem.Version`) 옛 저장은 읽지 않는다.

## 표 팩
다른 PC의 Sandbox에서 쓰던 표를 이미 설치된 앱(휴대폰·PC 빠른 한 판)에서 그대로 쓴다. 형식: [table-pack](../csv/table-pack.md).
- 내보내기(Sandbox 툴바 **팩 내보내기**): 지금 쓰는 표 전부를 zip 하나로 저장한다. 상태 줄에 팩 이름·ID·표 수가 뜬다.
- 가져오기(시작 화면 **표 가져오기**): 안드로이드는 시스템 파일 고르기, PC는 파일 열기 창으로 zip을 고른다. 매니페스트와 표마다 해시가 맞으면 `Application.persistentDataPath/TablePack/`에 풀고 화면을 다시 연다. 하나라도 틀리면 아무것도 바꾸지 않고 이유를 보인다.
- 팩이 있으면 빠른 한 판은 기본 표 대신 그 폴더를 읽는다. 팩에 없는 표는 기본 표, 팩의 `Strings.csv`에 없는 키는 기본 번역 표에서 채운다(옛 빌드에서 내보낸 팩). 이 앱이 모르는 표는 풀지 않는다.
- **기본 표**: 가져온 팩을 지우고 화면을 다시 연다.
- 샌드박스·데모 씬은 팩을 읽지 않는다.

## 메뉴
상단 막대 **메뉴** 또는 `Esc`(안드로이드 뒤로 가기): **계속하기** · **새 게임**(진행 중이면 한 번 묻는다) · **메인 화면**(저장하고 시작 화면으로) · **언어**. 샌드박스·데모는 새 게임·메인 화면 대신 **다시 시작**.
`Esc`는 가장 위에 열린 것부터 닫는다: 대화 상자 → 신앙 펀치 → 기술 트리 → 정보 패널 → (아무것도 없으면) 메뉴.

## 화면 배치
PC와 휴대폰(가로·세로)이 같은 화면을 쓴다. 크기는 UI 단위이고, 화면 픽셀로의 배율은 [UI 해상도](../csv/sprites.md#ui-해상도) 규칙을 따른다 — 그래서 논리 화면은 PC(1080p) 1280x720, 휴대폰 가로 약 900x400, 세로 약 430x960이고 버튼은 손가락 크기(약 7mm) 이상이다. 모든 화면은 안전 영역(카메라 구멍·제스처 바 제외) 안에 놓인다.
배치는 안전 영역 폭으로 고른다: 폭이 `UiKit.CompactWidth` 이상이면 넓은 배치, 좁으면(휴대폰 세로) 좁은 배치. 화면을 돌리면 그 자리에서 다시 배치한다.

| | 넓은 배치 | 좁은 배치 |
|---|---|---|
| 상단 막대 | 한 줄: 메뉴 · 턴 · 별 · 유닛 · 점수 · 신앙 · 기술트리 | 두 줄: 위 메뉴 · 턴 · 별 · 유닛, 아래 점수 · 신앙 · 기술트리 |
| 정보 패널·신앙 펀치 | 오른쪽 열 | 아래 시트(폭 전체, 화면 절반까지) |
| 설명 말풍선 | 왼쪽 아래 | 상단 막대 아래 |
| 기술 트리·종족 고르기의 상세 | 오른쪽 열 | 아래 띠 |

- 상단 막대: 턴은 팀 색, 별은 턴당 수입, 유닛은 수/수용량, 신앙은 게이지와 다음 턴 수입(누르면 신앙 펀치). 대신전이 있으면 막대 아래 오른쪽에 진행 상태.
- 정보 패널: 고른 유닛(이름, 소속·베테랑 진행, 체력·공격·방어·이동·사거리, 패시브 배지)이나 칸·도시(구조물, 도시 정보, 과업)와, 지금 할 수 있는 행동을 한 목록으로(방어·치유·자폭·대기·기도, 점령·탐험·해산·업그레이드, 훈련·보상·건설). 못 하는 행동은 이유와 함께 흐리게. 길면 스크롤, 닫기(X)는 선택 해제.
- 지도 위 유닛 행동 표시(규칙은 [unit](unit.md)·[combat](combat.md)·[movement](movement.md), 화면만 바꾼다):
  - 고른 아군: 그 칸에 노란 테두리, 갈 수 있는 칸은 파랑, 칠 수 있는 대상(공격·침투·약탈·폭우)은 빨강.
  - 이동: 경로 탐색이 고른 칸을 하나씩(상하좌우로) 밟으며 칸마다 한 번 통통 뛴다. 적 유닛도 같다 — 적 턴에는 이동이 다 끝난 뒤 공격이 이어진다.
  - 공격: 공격자가 대상 쪽으로 찌르고 → 대상에 빨간 피해 숫자와 붉은 번쩍임 → 반격이 있으면 잠깐 뒤 대상이 되찌르고 공격자에 피해 숫자. 적 턴의 공격도 이동이 끝난 뒤 하나씩 이 순서로 보인다.
  - 스플래시·짓밟기: 주변 유닛의 피해 숫자는 주 대상과 같은 순간(짓밟기는 이동 직후)에 함께 뜨고, 로그에 `UI.Log.Splash` 줄이 남는다.
  - 체력 숫자·막대는 맞기 전 값에 머물다가 피해 숫자가 뜨는 순간 줄어든다(적 턴도 공격을 하나씩 보여줄 때). 처치된 유닛은 자기 피해 숫자가 뜬 뒤 깜빡이며 사라진다. 치유·대기 회복은 초록 `+N`.
  - 이번 턴 더 할 수 있는 행동이 없는 아군(행동을 마쳤고 더 움직일 수 없음, 빙결 포함)은 회색으로 어두워진다. 내 턴이 시작되면 돌아온다.
  - 행동 화면 녹화: [README](../../../README.md#실행) "유닛 행동 GIF".
- 오른쪽 아래 **턴 종료**, 왼쪽 위 알림(행동 기록이 몇 줄 떴다가 사라진다), 가운데 대화 상자(화면 폭에 맞춘다).
- 지도: 끌어서(마우스 왼쪽·한 손가락) 옮기고 휠·두 손가락 핀치로 확대한다. 시작 화면·기술 트리·대화 상자가 열려 있으면 지도는 움직이지 않고, 패널 위의 휠은 그 목록을 스크롤한다.
- 기술 트리: 전체 화면 창. 가운데 허브에서 갈래가 방사형으로 뻗고 티어마다 바깥 원(2티어부터는 갈래 안에서 좌우로 갈라진다). 나무는 끌어서 옮기고 휠·핀치로 확대한다(나무 가장자리가 창 가운데까지 온다). 열 때와 창 크기가 바뀔 때 허브를 가운데로, 나무가 들어가는 배율로 맞추되 노드가 너무 작아지지 않게 하한을 둔다 — 휴대폰에서는 바깥 원이 화면 밖에 있어 끌어서 본다.
- 휴대폰은 가로·세로 모두 쓴다(자동 회전, 빌드 설정 — [README](../../../README.md#실행)).
